package com.example.funding;

import org.springframework.boot.CommandLineRunner;
import org.springframework.context.annotation.Profile;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Component;

@Component
@Profile("db-check")
public class DatabaseReadCheck implements CommandLineRunner {
    private final JdbcTemplate jdbcTemplate;

    public DatabaseReadCheck(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @Override
    public void run(String... args) {
        String name = jdbcTemplate.queryForObject(
                "SELECT name FROM research_project WHERE id = 1",
                String.class
        );
        System.out.println("数据库项目名称：" + name);
    }
}

这段代码的新知识围绕一个目的：启动后执行查询。
- @Component：让Spring管理这个类，并通过构造方法提供JdbcTemplate。
- @Profile("db-check")：只有启用db-check检查模式时才使用它。
- implements CommandLineRunner：遵守启动执行约定；Spring在启动过程中调用run方法。@Override表示实现该约定的方法。
- private final：字段仅供类内部使用，赋值后不能改指向；构造方法里的this赋值与你学过的一样。
- String... args：接收可变数量的启动参数，这次不用。
- queryForObject：查询一个结果；String.class说明期望得到字符串。
