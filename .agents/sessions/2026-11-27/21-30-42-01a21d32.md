```java
@GetMapping("/api/projects/{projectId}/applications/me")
public ResponseEntity<List<OwnApplication>> getOwnApplications(
        @PathVariable("projectId") long projectId,
        HttpServletRequest request) {
    var session = request.getSession(false);
    Long currentUserId = session == null ? null : (Long) session.getAttribute("userId");
    if (currentUserId == null) {
        return ResponseEntity.status(401).build();
    }

    if (!draftRepository.isProjectMember(projectId, currentUserId)) {
        return ResponseEntity.status(403).build();
    }

    return ResponseEntity.ok(
            draftRepository.findOwnApplications(projectId, currentUserId)
    );
}
```

`projectId` 来自 URL，`currentUserId` 来自登录 Session。没有登录身份时返回 `401`，已登录但未加入目标项目时返回 `403`。通过成员检查后，Repository 用项目和当前用户一起筛选，成功时返回 `200`，没有本人记录时响应体是 `[]`。

### 先写财务待结算查询

在 [DraftRepository.java](../../../backend/src/main/java/com/example/funding/DraftRepository.java:268) 中，把下面的类型和方法加在 `ApplicationSummary` 前面。

```java
public record PendingSettlement(
        long applicationId, long applicantId, String purpose,
        long requestedFen, long approvedFen
) {}

public List<PendingSettlement> findPendingSettlementsByProject(long projectId) {
    String sql = """
            SELECT id, applicant_id, purpose, requested_fen, approved_fen
            FROM funding_application
            WHERE project_id = ?
              AND status = 'APPROVED'
            ORDER BY id
            """;

    return jdbcTemplate.query(
            sql,
            (rs, rowNum) -> new PendingSettlement(
                    rs.getLong("id"),
                    rs.getLong("applicant_id"),
                    rs.getString("purpose"),
                    rs.getLong("requested_fen"),
                    rs.getLong("approved_fen")
            ),
            projectId
    );
}
```

`project_id` 把结果限定在目标项目，`APPROVED` 筛出已批准、仍待结算的申请。单独返回 `approvedFen`，因为财务登记的实际支出以**批准金额**为上限。数据库约束要求 `APPROVED` 记录有批准金额，因此这里可以用 `long`。
