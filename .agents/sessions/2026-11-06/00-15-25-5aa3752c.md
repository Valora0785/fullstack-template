### 最终对外答复
这三个概念可以放进同一段代码理解。下面先看结构，不用急着复制：

```java
@RestController
public class HealthController {

    @GetMapping("/api/health")
    public String health() {
        return "backend is running";
    }
}
```

**1. “控制器”是什么？** :codex-annotation{index="1"}

控制器是**负责接收和处理网页请求的 Java 类**。这里的 `HealthController` 就是我们准备编写的控制器。

你以前的 `Member` 类用于表示成员；这里的 `HealthController` 类用于提供请求入口。浏览器不能随便输入一个 Java 方法名就调用它，我们需要告诉 Spring：收到什么请求时，执行哪个方法。

所以，“没有处理 `/api/health` 的控制器”就是：**目前还没有把这个请求与对应的 Java 处理方法连接起来。**

**2. `@GetMapping` 是什么意思？** :codex-annotation{index="2"}

以 `@` 开头的这种标记叫**注解**，Java 或框架可以读取它，按它提供的信息工作。

```java
@GetMapping("/api/health")
```

可以读成：

> 收到 GET 请求，且路径是 /api/health 时，执行下面这个方法。

其中：

- **Get**：指定 GET 请求，通常用于获取内容。
- **Mapping**：映射，也就是建立“请求 → 方法”的对应关系。
- **`"/api/health"`**：要匹配的路径，不包含主机和端口。

因此，浏览器访问该地址时，Spring 会按这个标记找到 `health()`。方法名不必与路径相同，路径由注解中的配置确定。[官方请求映射说明](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-requestmapping.html)

**3. `@RestController` 是什么意思？** :codex-annotation{index="3"}

它标在**类上方**，主要告诉 Spring 两件事：

1. 这个类是处理请求的控制器。
2. 处理请求的方法所返回的值，要作为响应内容发送给请求方。

所以这里：

```java
return "backend is running";
```

会让浏览器收到文字 `backend is running`。以后返回项目、申请等对象时，也可以由框架转换成适合前端读取的数据。[官方控制器说明](https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann.html)

把整个过程连起来就是：

```text
浏览器请求 GET /api/health
        ↓
Spring 根据 @GetMapping 找到 health()
        ↓
执行方法，返回字符串
        ↓
@RestController 使返回值成为响应内容
        ↓
浏览器收到 backend is running
```

**1. 包是什么，为什么要用包？** :codex-annotation{index="1"}

你现在写的是：

- **分类和查找：**项目变大后，可以把成员、项目、申请等相关代码按职责组织起来。
- **区分重名的类：**不同包可以各自有一个 `Member` 类，完整名称不同，就能区分。

包名通常全小写，常用“倒写域名 + 项目名”的形式；`com.example` 是我们使用的示例前缀，`funding` 表示经费项目，不需要为它购买域名。[官方包命名说明](https://docs.oracle.com/javase/tutorial/java/package/namingpkgs.html)

**3. 为什么这里首字母没有大写？** :codex-annotation{index="3"}

你可能指的是 `class`，也可能是方法名 `health`。它们与类名的规则不同：

```java
public class HealthController {
    public String health() {
        return "backend is running";
    }
}
```

| 名称 | 是什么 | 大小写原因 |
|---|---|---|
| `class` | Java 关键字，表示“声明类” | 固定写法，必须这样小写 |
| `HealthController` | 我们取的类名 | 按命名惯例，每个单词首字母大写 |
| `health` | 我们取的方法名 | 按命名惯例，第一个单词首字母小写 |
| `String` | Java 提供的类型名称 | 使用它原本的大小写 |

**“类名首字母大写”说的是 `HealthController`，不是它前面的关键字 `class`。**

这里还要区分：关键字写法是语言规则；类名、方法名的上述大小写是命名惯例。例如把类取成小写开头，可能仍能编译，但不符合常用规范。Java 区分大小写，`class` 改成 `Class` 后，就不再是声明类的那个关键字。
