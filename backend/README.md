# 后端工程

页面发出请求后，后端负责接收和处理，再把结果返回给前端。后端工程放在这里，固定使用 Spring Boot。已完成最小工程初始化和服务检查接口；运行方法及实际验证范围见下方“当前可运行版本”。项目流程和 Git 规范见[根 README](../README.md)。

刚学 Java 或 SQL 时，可以先保存能独立运行的类、建表和查询练习，写明运行方式。学到框架后再整理到 Spring Boot 工程，不必先完成全部前端或 PR 练习。

## 先弄清要准备哪些工具

JDK 是 Java 开发工具包。后端工程需要兼容的 JDK 和构建工具，不能只凭教程中的版本号安装。先确定要使用的 Spring Boot 版本，再查看该版本的官方要求，亲自准备环境并记录实际版本。

构建工具负责管理依赖，执行编译、测试等操作。可以选择 Maven 或 Gradle，先了解基本用途再决定。项目所需的其他依赖和附加服务，按实际任务选择，不要求把教程提到的工具全部装上。

不清楚某个工具为什么需要，可以请 agent 解释，也可以让它帮你分析安装错误。基础工具安装和系统配置仍由你亲自操作。

## 自己创建工程，再检查是否可用

可以使用 Spring Initializr 生成工程。你需要自己选择选项并执行生成，不要求把生成器提供的初始文件全部手写一遍，也不能让 agent 替你初始化。

把生成的工程放到本目录，保留必要的 `README.md`、`AGENTS.md` 和忽略规则，工程文件直接位于这里。

创建后先确认能够构建，再启动服务。按照实际日志检查启动结果，不把“执行了命令”当作“已经启动”。环境没有准备好时，先处理环境问题，再继续验证。

## 接口要实际调用

接口是后端接受请求、返回结果的入口。服务启动成功后，还需要发出请求，检查状态和返回数据。接入前端时，要确认页面实际请求了这个服务。

已有测试要运行。编译成功、服务启动和接口行为符合预期，分别说明不同结果，不能互相代替。记录验证时写出实际做了什么；没有执行的检查说明原因，计划执行的命令不能算测试结果。

## 当前可运行版本

当前只实现服务检查接口，尚无数据库、登录或经费业务。

### 已采用的工具

- Java：JDK 21；学员终端已确认版本为 21.0.13.0.2。
- Spring Boot：4.1.2。
- Maven：3.10.0，由 Maven Wrapper 调用。
- Maven Wrapper：3.3.4，脚本和配置随工程保存。
- 主要依赖：Spring Web MVC；生成器附带配套测试依赖。
- 工程来源：学员亲自使用 Spring Initializr 生成，控制器由 Codex 提供指导、学员写入。

### 获取依赖、测试与构建

先在仓库根目录打开终端，再进入后端：

```sh
cd backend
./mvnw package
```

首次执行需要网络，Wrapper 会按配置下载 Maven，Maven 按 pom.xml 下载依赖及插件。package 会执行编译、已有测试和打包；成功时末尾出现 BUILD SUCCESS。依赖下载到本地缓存，后续按需复用。

产物为 target/backend-0.0.1-SNAPSHOT.jar。源码修改后需要重新构建，旧 Jar 不会自动包含新代码。target 是构建输出，不提交。

### 启动与停止

在 backend 目录中，构建成功后执行：

```sh
java -jar target/backend-0.0.1-SNAPSHOT.jar
```

当前默认 HTTP 端口为 8080。启动日志应包含 Tomcat started on port 8080 和 Started BackendApplication。服务会持续运行；在该终端按 Control+C 停止。

也可以在 IDEA 中运行 BackendApplication.main。当前学员已验证的 IDEA 启动使用 8080；两种启动方式任选其一，避免同时争用同一端口。

需要临时指定其他端口时，例如此前已实际使用的 18080：

```sh
java -jar target/backend-0.0.1-SNAPSHOT.jar --server.port=18080
```

这个参数只影响当次启动。访问接口时，端口必须与本次启动日志一致。IDEA 运行时使用其自己的运行配置，不自动沿用上述命令参数。

### 请求与预期结果

默认端口下，在浏览器访问：

```text
GET http://localhost:8080/api/health
```

预期状态为 200，响应正文为 backend is running。通过开发者工具 Network 查看请求地址、方法、状态与 Response。此接口仅返回固定文字，不检查数据库或经费业务。

根路径 / 暂未提供首页，返回 404 属于当前预期。连接被拒绝则应先核对服务是否运行、请求端口是否正确；不能与 HTTP 404 混为一谈。
