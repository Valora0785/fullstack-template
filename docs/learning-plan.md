# 经费管理系统学习计划

## 一、我对项目的理解
这个系统主要是帮科研团队把项目经费管清楚，减少手工记账出错的情况。成员需要买设备或材料时，先提交申请，由老师审批，买完后再由财务登记实际花了多少钱。这样就能查清楚谁申请买了什么、老师批了多少钱、最后花了多少，以及项目还剩多少钱，大家也更容易了解经费的使用情况，让申请和审批更规范。
